# DatasetForge AI

**Autonomous Multi-Modal Dataset Cleaner & Unified MLOps Suite**

DatasetForge AI is a production-grade software designed to ingest, clean, tokenize, balance (SMOTE), and compile multi-modal technical datasets (C++, Java, Python, SQL, Linux, Cyber Security, and Numerical embeddings) into **a single unified mixed dataset file** ready for instant CSV/JSON export and custom AI training.

## 🌟 Core Capabilities
* **Universal Ingestion:** Automatically detects and ingests multi-modal data from C++, Java, Python, SQL, Linux, Cyber Security, and numerical formats.
* **Autonomous Cleaning:** Performs advanced missing value imputation, noise/outlier removal, and schema inspection.
* **SMOTE Balancing & Augmentation:** Balances class distributions and normalizes features for robust machine learning pipelines.
* **Unified 1-Click Export:** Merges all mixed modalities into a single clean dataset exportable instantly as CSV or JSON.

## 📂 Repository Structure
* `index.html`: Fully interactive frontend dashboard built with Tailwind CSS, Chart.js, and Lucide Icons.
* `app.py`: FastAPI Python backend for advanced data cleaning, missing value imputation, and pipeline execution.
* `token_engine.cpp`: C++ high-speed tokenization & schema inspection module.
* `requirements.txt`: Python package dependencies.
* `.gitignore`: Git configuration to ignore unnecessary build/cache files.
